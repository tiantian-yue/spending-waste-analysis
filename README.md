《大数据技术与应用》课程大作业与毕业设计共用本代码库。

## 题目

**高校二手教材交易平台的设计与实现**

## 技术栈

| 层 | 技术 | 版本 |
|----|------|------|
| 后端 | Flask | 3.1.3 |
| ORM | Flask-SQLAlchemy | 3.1.1 |
| 数据库驱动 | PyMySQL | 1.2.3 |
| 配置 | python-dotenv | 1.2.4 |
| 数据库 | MySQL | 8.0.46 |

## 目录结构

```
textbook-trading/
├── app/                    应用主体
│   ├── __init__.py         应用工厂（只装配，零业务）
│   ├── config.py           配置（敏感项走环境变量）
│   ├── models/             数据模型（ORM）
│   ├── routes/             路由层（只做参数校验与响应组织）
│   ├── services/           业务逻辑层（核心规则写在这里）
│   └── templates/          页面模板
├── sql/                    建库脚本与演示数据
├── docs/decisions/         架构决策记录（ADR）与未决事项
├── tests/                  测试
├── run.py                  本地启动入口
├── requirements.txt        依赖（版本锚定）
└── .env.example            环境变量模板
```

分层依赖方向单向向下：`routes -> services -> models`。禁止反向引用。

## 本地启动

```bash
# 1. 复制环境变量模板
cp .env.example .env
# 2. 按本机情况修改 .env 里的 DB_PASSWORD
# 3. 启动
python run.py
```

启动后访问 http://127.0.0.1:5000/health ，返回 `{"status": "ok"}` 表示环境正常。

## 数据库

使用 MySQL 8.0。库名 `textbook_trading`，字符集 `utf8mb4`。

建库脚本见 `sql/` 目录（随设计阶段推进逐步补齐）。

## 开发约定

- 单文件不超过 300 行，超出即拆分
- 敏感信息（数据库密码、密钥）一律走 `.env`，不写进代码、不提交
- 依赖版本锚定到具体版本号，不使用 `latest`
- 不使用 emoji 作为界面图标，统一使用 SVG 图标方案
- 提交信息写明做了什么，便于日后作为开发过程记录
